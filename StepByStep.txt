# ---------- 3b. G2P (Persian script -> phonemes for v2) ----------
# v2 takes romanised phonemes, NOT Persian script. Persian text passed directly
# produces silence: every Persian character maps to the unknown token, the model
# is conditioned on nothing, and it emits end-of-speech immediately.
# Phonemise first with Homo-GE2PE, then feed the phonemes with --no-normalize-text.
# Working script (prints raw G2P + pocket-tts phonemes, saves phonemes.txt):
.\.venv\Scripts\python.exe .\g2p_test.py
# Expected output for "سلام، حال شما چطور است؟":
#   raw:      s/lam hale1 $oma cetor @/st
#   phonemes: salAm hAle1 SomA Cetor ?ast   (KEEP the 1: ezafe mark, synthesize.py strips it)
# G2P folders: use Models\Homo-GE2PE-Persian-HF (or -HF-clean, identical weights).
# Do NOT point at Models\Homo-GE2PE-Persian-original: raw vendor dump (zipped
# weights + vendored Parsivar, no top-level config.json) -> "Unrecognized model".
# NOTE: both -HF configs shipped with "tie_word_embeddings": true, which makes
# transformers drop the checkpoint's real lm_head.weight (52 params incl. a
# distinct lm_head) and tie it to shared.weight instead -> garbage output
# (repeated i/1 tokens). Fixed to false in -HF and -HF-clean (matches the
# original homo-ge2pe/config.json). If you re-download, re-apply this fix.

# ---------- 4. Synthesize (phoneme input! Persian script -> silence) ----------
# model_farsi_local.yaml at repo root = copy of Models\pocket-tts-farsi-v2\model.yaml
# with weights_path/tokenizer_path rewritten to local E:/AI/... absolute paths
# so no HuggingFace download happens at runtime.
# "salAm hAle SomA Cetor ?ast" = phonemes for "سلام، حال شما چطور است؟" (see Models\pocket-tts-farsi-v2\README.md phonemise()).
# --voice-sec 5 trims the prompt (training cap was 5s; longer prompts replay the prompt).
# --no-normalize-text = correct here ONLY because input is already phonemes (else keep default).
.\.venv\Scripts\python.exe -m training.farsi.synthesize `
    --config .\model_farsi_local.yaml `
    --voice .\training\farsi\examples\01_greeting.wav `
    --voice-sec 5 `
    --no-normalize-text `
    --text "salAm hAle SomA Cetor ?ast" `
    --out .\test_fa.wav


.\.venv\Scripts\python.exe -m training.farsi.synthesize --config .\model_farsi_local.yaml --voice .\Models\pocket-tts-farsi-v2\samples\prompt_hello.wav --voice-sec 5 --no-normalize-text --text "salAm hAle SomA Cetor ?ast" --out .\test_fa.wav

# ---------- 5. Serve (optional) ----------
.\.venv\Scripts\python.exe -m pocket_tts.main serve
